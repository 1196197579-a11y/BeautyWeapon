# 美丽武器

Windows 本地离线视频合成与直播输出工具。读取抖音用户主页的头像和昵称后，随机使用一个可用模板自动合成，核对后手动播放。

## 使用

从 [Releases](https://github.com/1196197579-a11y/BeautyWeapon/releases) 下载完整包，解压后运行根目录唯一的启动 EXE，保留整个文件夹。浏览器加载包内抖音网页助手文件夹。

V7.1.1 随机使用所有未归档模板，新模板自动参与；每轮读取只抽一次，允许重复，缺素材模板跳过，无可用模板时停止。设置中可关闭随机。直播模式自动缩小窗口，提供立即播放及独立打开输出窗口。

设置支持内置或 NDM 下载，更新使用独立新目录，保留旧版本与下载文件。扩展有变化时仍需在浏览器手动加载。

打开用户主页不能证明送礼身份，播放前请核对用户。用户资料发送到本机服务；本工具不读取私信或自动操作送礼。

源码涵盖新增启动器、更新器、前端扩展和网页助手；兼容引擎缺少完整源码，因此本仓库不是完整引擎重编译工程。FFmpeg 许可证随完整包提供。源码重建脚本应在完整包的 components/runtime/v711_source 中运行。
