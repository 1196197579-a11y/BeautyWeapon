# 美丽武器 V8.1.3 诊断版

新增桌面读取失败日志、助手页面诊断、通信错误记录、旧任务导出与离线诊断缓冲，保留原模板、素材、随机制片、持久队列和手动播放能力。

此版用于定位实际直播中的读取故障，尚不宣称现场故障已修复。已完成受控 Edge、真实 FFmpeg、失败日志落盘及临时页关闭测试；受控测试不等于真实直播验收。

现有程序：设置 → 检查更新。更新后在 Edge 加载 V8.1.3 网页助手、禁用旧助手并刷新直播平台。失败时桌面‘美丽武器_读取失败日志’自动保存 TXT。维护排查请提供最新详细日志；个人任务日志不应公开上传本仓库。
