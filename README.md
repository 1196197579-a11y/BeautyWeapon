# 美丽武器 V8.1.5

修复实际失败日志确认的 FFmpeg 合成超时，优化方向渐显，增加进度与停止任务；每次启动开启干净的新场次，旧任务及成片保留在设置的历史记录。稳定空列表首条礼物可捕获，绿色立即播放统一队列播放，日志工具移入设置。保留原身份验证、Emoji、模板素材、随机制片和手动操作。

自测包含实际三套模板、真实 FFmpeg、独立 Edge 多用户连续任务、应用真实重启、浏览器旧缓冲隔离、任务取消及渐显像素对比。受控测试中错误用户视频与误关非任务页为零；真实直播仍需复验，不承诺零漏单。个人素材、任务及日志不上传本仓库。

设置 → 检查更新。更新后必须在 Edge 加载 V8.1.5 网页助手、禁用旧助手并刷新直播平台。
