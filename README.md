# 美丽武器 V8.1.1

直播回馈视频工具。V8.1.1 修复常见延迟打开主页的送礼任务失败，保留独立身份校验、随机制片和手动播放。

已安装 V8.1：在程序中选择“设置 → 检查更新”，等待自动下载安装并切换；旧版与用户数据保留。本次必须在 Edge 加载 V8.1.1 网页助手、禁用旧助手并刷新直播平台；新版设置提供打开助手文件夹按钮。

新安装：[完整版本下载](https://github.com/1196197579-a11y/BeautyWeapon/releases/tag/v8.1.1)。完整解压后启动根目录 EXE，并加载包内 Edge 助手。跨电脑迁移素材请导出/导入“模板＋素材”。

V8 的送礼监听、账号验证、随机模板制片和持久待播队列已完成受控 Edge/FFmpeg 测试；真实抖音直播环境遮挡监听、漏单率和长时间运行尚待现场验收，不能宣称零漏单。无法可靠验证身份时停止制片。

源码：src/v8.1.1；使用说明随完整包附带。原 Go 核心二进制保留，并未从原源码重建。旧版本发布继续保留。
