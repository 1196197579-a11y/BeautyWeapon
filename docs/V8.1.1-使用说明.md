# 美丽武器 V8.1.1 使用说明

本版修复 V8.1 在礼物入队后“点击未同步返回唯一主页地址”的常见延迟打开场景。保留 V8.1 的排版、头像图标、设置、模板、素材、随机制片、持久队列、原手动读取/合成/播放和内置/NDM 更新功能。

## 必须完成的一次助手更新

1. 结束当前播放/合成，在旧版“设置 → 检查更新”选择内置下载器，等待新目录安装和自动切换。旧目录保留，不需要删除文件。更新源仍是 https://raw.githubusercontent.com/1196197579-a11y/BeautyWeapon/main/latest.json 。
2. 新版“设置 → 打开新版网页助手文件夹”。在 Edge 的 edge://extensions/ 开启开发人员模式，禁用旧美丽武器助手，加载此文件夹“美丽武器V8.1.1_抖音网页助手”。不要同时启用两套助手，不需要删除旧助手文件夹。
3. 刷新已经打开的 https://anchor.douyin.com/ 平台页面。仅重新加载扩展而不刷新旧页面，不能替换已注入页面的旧代码。
4. 展开礼物明细，在程序中开启自动监听。看到“礼物明细已连接”后，再送出新的测试礼物。开启前已显示的记录仅作为基线，不会补做。

本次程序更新不会代替浏览器确认扩展更新。仍使用旧助手时，程序会暂停监听并提示更新助手；原手动主页读取继续兼容旧助手。

## 正常直播流程

先检查至少一个未归档的完整模板可以正常合成。保持 Edge 礼物明细展开、只开一张监听平台页，并将平台与用户主页加入 Edge 始终活动的网站，避免睡眠/丢弃。

新送礼 → 独立任务 → 获取并验证账号/头像/完整昵称 → 随机有效模板 → 合成 → 待播放。普通模式点击“播放下一条”，或在直播模式核对头像和昵称后点击“立即播放”。不会自动播放下一条；“打开直播输出窗口”只打开窗口。

## 本次修复及边界

主页地址不再要求在 click() 的同一调用栈立即返回。助手跟踪该原始点击创建的定时器、Promise 回调及后续回调链，另支持先创建空白页句柄、稍后指定主页地址；每个地址携带本次点击的独立上下文。取得地址后仍只创建一张带任务标记的非活动主页，验证后关闭。

不会把“恰好在点击后打开的网页”直接认作任务主页。无任务上下文的并发打开、多个不同账号地址、原礼物行被移除/复用、过期回调都会拒绝；无法追踪的原生 async/await 直接打开主页仍可能需要人工核对，不能靠等待时间或昵称猜账号。

昵称、头像、主页唯一账号标识和原礼物记录的绑定校验保持。不能证明身份时不合成、不开播，也不关闭其他标签页。实际直播 DOM、回调方式、窗口被直播伴侣覆盖和长时间运行仍需现场复测；没有独立记录编号的重复内容/虚拟列表复用仍有漏单风险，不宣称零漏单。

## 旧任务和异常按钮

同机模板、素材、更新/NDM 设置和 automation-v8 任务存档保持原位置。以前已经失败的两条任务继续保留；刷新后旧礼物行的节点标记可能失效，不能凭昵称自动补做。应从原送礼记录核对用户主页，用“核对身份”填写完整地址后重试；不再需要的失败任务可“归档异常”，不删除文件。

“重试”重跑身份验证；“重新选模板”针对素材/模板失败；“开始新场次”须先关闭监听、处理完任务并等待助手缓冲清空。归档异常不表示任务已合成或已播放。

换电脑请先导出、导入“模板＋素材”；完整 ZIP 不包含私人素材或抖音登录资料。回滚时退出新版，在旧入口传入 --skip-active；不要删除 active.json 或任务目录。原 Go 核心、后台及 FFmpeg 位于 components，仍是必要组件。

源码和重建脚本：components/runtime/v811_source。新 EXE 已实际重建；旧 Go 二进制原样保留。没有删除用户文件。
