# 美丽武器 V8.1 使用说明

V8.1 基于 V8.0 完整包，主要调整排版、EXE 图标和直接更新交付。原模板、素材、设置、送礼队列、随机合成和手动播放保留。

## 从 V8.0 直接更新

在当前程序右上角点击“设置 → 检查更新”。使用内置下载器时，检查到 V8.1 后自动下载、校验并安装到旁边的新目录；空闲时自动切换，旧版与下载包保留。NDM 方式沿用原配置，每次下载重新连接，仍可能由 NDM 自己显示“开始下载”确认。

V8.0 已加载的网页助手与 V8.1 兼容，本次无需重新加载助手，也无需重新导入同一台电脑已有的模板与素材。程序共享原有专用界面资料和 `%LOCALAPPDATA%\BeautyWeapon` 设置，送礼队列仍位于 `automation-v8`。原来的 EXE 启动入口在成功更新后会转到已验证的新版。

更新前先停止正在进行的直播操作；程序也会等待当前合成、播放或模板载入完成。正式更新源为 https://raw.githubusercontent.com/1196197579-a11y/BeautyWeapon/main/latest.json 。如您手动改过更新源，请确认使用本仓库源。不要删除旧目录或数据目录作为更新步骤。

## 手动安装和回滚

完整解压本包，退出旧版后启动根目录唯一入口“美丽武器V8.1.exe”。原 Go 核心、后台、FFmpeg 等位于 components，均为必要组件。

首次安装浏览器助手，或从 V7.1.x 升级后使用送礼监听，请在 Edge 加载本包“美丽武器V8.1_抖音网页助手”文件夹。已有 V8.0 助手可继续使用。将来涉及新增浏览器权限或协议时仍需按更新说明处理，不能保证任何助手版本永久兼容。

手动回滚时，退出新版，启动保留的旧版 EXE 并传入 `--skip-active` 可跳过已安装新版的转发；不要删除 active.json 或用户素材。两个版本不能同时占用同一本地服务端口。

## 界面变化

- “模板与素材”现在位于左侧素材导入下方：保存、加载、重命名、归档、导出、导入、恢复归档和素材摘要都保留。
- 服务状态、设置、切换模式相邻放在右上角；直播模式也显示状态。状态过长时可将鼠标停在状态上查看完整文字。
- EXE 图标与软件内头像使用同一图片，包含 16/24/32/48/64/128/256 像素图标。
- 左右侧内容较多时可滚动，中心预览区保持独立。

送礼监听的现场验收状态与 V8.0 一致：受控页面链路已自测，但尚未完成已登录抖音的真实直播伴侣覆盖和长时间运行验收。不能宣称零漏单。详细机制和现场清单保存在“V8.0_基线资料”，其中旧版更新源未发布的说明仅代表旧版当时状态。

换到另一台电脑仍须在旧版导出“模板＋素材”后导入；ZIP 不自动包含您电脑上的私人素材或登录资料。

V8.1 源码及重建脚本位于 components/runtime/v81_source。此升级没有删除用户文件。
