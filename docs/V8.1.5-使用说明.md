# 美丽武器 V8.1.5

本版按实际失败日志修复合成超时，并纠正重启面板仍累加旧统计的行为。保留 V8.1.4 的全部手动操作、素材、模板、随机制片、身份验证、表情、输出窗口、设置和更新功能。

## 更新后使用

1. 旧程序“设置 → 检查更新”，使用内置下载器或已经配置的 NDM。校验后旁边新建版本目录并切换启动入口，旧版本保留。
2. 新版“设置 → 打开新版网页助手文件夹”。Edge 扩展中禁用旧助手，加载“美丽武器V8.1.5_抖音网页助手”，刷新直播服务平台。浏览器确认和扩展换版仍需本人操作；软件更新不能替换已加载的扩展代码。
3. 保持 Edge 直播服务平台开启，开启“自动监听”。本版只接受具有新场次协议的助手，旧助手会被明确暂停。
4. 新礼物独立入队 → 核对任务账号并读取资料 → 随机使用可用模板合成 → 待播。合成中显示阶段、进度、耗时；成功后普通和直播模式的“立即播放”变为鲜绿色，点击播放最早就绪的视频。仍由本人决定播放，不会自动播放或覆盖正在播放的视频。
5. 需要中止时，使用任务下方“停止任务”；随后可以重试。“清空头像/昵称”只清理手动资料，不等同于停止队列任务。

## 每次启动干净面板

每次启动自动建立新场次：当前头像、昵称、手动输入、当前任务列表、已收数量、完成数量、异常和捕获警告全部重新开始。旧成片和旧任务留在“设置 → 场次、历史任务与诊断 → 查看历史任务”，不会自动继续合成，也不会再次计入本次已收数量。

已就绪的历史成片可“恢复到待播队列”，恢复前重新核验视频 SHA256，直接播放，不重新合成。历史未完成任务可“恢复并重新读取”，必须重新验证身份。浏览器在上次退出前没有提交成功的礼物会保留到原场次历史，避免重启后又增加本次统计。

原“开始新场次”按钮移入设置，改名“归档当前场次并清空面板”。它可在监听开启、存在异常或待播任务时使用；正在播放或手动合成时需等结束。自动合成会停止，任务和视频保留供恢复；不删除文件。停止任务和归档会影响正在处理的工作，请按实际需要使用。

## 超时与速度

上传日志中的抖音任务已通过身份检查，实际失败发生在 FFmpeg 合成阶段；不是头像或 Emoji 读取失败。旧的方向渐显会在整段视频反复计算每个像素，本版只在首秒处理透明通道，并保留方向与柔和边缘。已与旧版左右渐显逐帧对比。

进程等待改为有界等待，停止时结束本软件创建的 FFmpeg 进程树。连续 45 秒没有新视频帧，或超过按源视频时长计算的 60～300 秒预算，会失败并释放任务，给出诊断。耗时依赖视频、模板和直播电脑负载，不能仅靠延长超时保证成功。进程卡顿和真实错误仍可能发生，但不会无限占用同一合成锁。

自动流程额外包含礼物检测、头像下载、身份核对及素材装载，所以不能保证与已经装载素材的手动点击耗时相同。本版复用受限的制片页面、缓存应用会话，避免重复请求和重复视频全量解码校验。

复制本机应用自己的三套模板到隔离环境，以受控礼物/主页测试：信纸约 12 秒，冰墙约 19 秒，擦玻璃约 20 秒，均成功进入待播队列并可播放。此数据包括读取与装载步骤，现场可能更慢，个人素材未随本版上传公开仓库。

## 捕获与诊断

稳定空列表中的第一条新礼物可被识别；需要证明是同一列表中的新插入。初次打开时已有记录、滚动复用、身份不确定仍不凭昵称猜测。三个最新失败日志属于同一抖音任务的重试，所查存档中没有独立玫瑰任务，因此不能把这些日志说成已经证明玫瑰失败原因。

读取、点击或合成失败继续写入桌面“美丽武器_读取失败日志”。现在合成诊断增加模板名称、阶段、帧数、耗时和 FFmpeg 错误摘要；捕获警告增加受限的列表观察信息，有助于区分漏捕与合成失败。设置中的“导出失败日志”和“打开日志文件夹”保留。只记录有限公开页面事实，不记录登录凭证、网页全文或图像内容，不上传个人诊断。

## 身份与表情

保留原送礼账号、每轮独立任务标记、稳定完整昵称与唯一关联头像的联合校验。账号冲突、头像不唯一、资料未稳定或任务不匹配仍停止。昵称不是唯一身份依据。

保留文本 Emoji 和图片 alt 中可靠的表情文字；比较统一 Unicode NFC 和可选显示选择符，不去掉肤色、连接符、旗帜或组合成员。显示昵称按完整字符簇截短，完整昵称保留供核对。11 类表情验证实际生产 PNG 图层与 FFmpeg 编解码视频像素。内置 Google Noto Color Emoji 字体按 OFL 1.1 分发，固定来源、SHA256 与授权位于 components/runtime/emoji。网页改版与未来新表情仍可能需要适配。

## 自测与边界

独立 Edge 中复测多个用户、同用户重复礼物、非活动标签页、资料不匹配拦截、真实 FFmpeg、普通模式绿色播放、停止真实合成、Service Worker 恢复和任务临时页关闭。实际结束应用再启动，确认本次统计与手动资料归零、历史任务保留；模拟助手旧缓冲跨场次提交，确认归到历史而非新面板。

受控测试中错误用户视频数和误关非任务页面数为零，测试期间没有新增可见控制台窗口。未进行用户真实直播送礼验收，不宣称零漏单，也不保证所有网站结构和系统负载下都无异常。

GUI 启动器和渐显 FFmpeg 包装器已重建。原 Go 核心、原后台与实际 FFmpeg 二进制保留，未从缺失的原 Go 源码重建。新版源码位于 components/runtime/v815_source，原 V8.1.4 运行脚本和包装器也归档在 components/versions。完整包每个 ZIP 条目与文件 SHA256 已校验。只操作程序受控数据和自己创建的临时标签页，未删除用户文件。
