# 美丽武器 V8.1.3 诊断版

本版增加失败诊断能力，不把尚未定位的现场读取故障说成已修复。所有原有合成、模板、播放、持久任务和更新能力继续保留。

## 更新和采集

1. 旧程序“设置 → 检查更新”，使用内置下载器更新到 V8.1.3。新目录安装，旧版保留。
2. 新版“设置 → 打开新版网页助手文件夹”。Edge 扩展中禁用旧助手，加载“美丽武器V8.1.3_抖音网页助手”，刷新直播平台。只更新 EXE 不会替换已注入网页的助手代码。
3. 开启自动监听；已有明确主页地址的失败任务可点一次“重试”，不必继续付费送礼。
4. 若再次失败，桌面“美丽武器_读取失败日志”自动新增 TXT。队列中可点“打开日志文件夹”。把该次最新的详细日志提供给维护者即可。

详细日志包括任务编号、读取阶段、助手版本、预期/当前/公开账号标识、昵称节点与头像候选、图片是否加载、页面是否隐藏/被丢弃、通信失败和临时标签页关闭结果。只记录有限的公开 DOM 字段，不读取 Cookie、登录凭证、网页全文或截图；图片地址去掉查询参数和任务标记。日志包含公开昵称/账号地址，请不要公开发布整份个人任务日志。

同一次失败可能生成基本失败记录和随后补齐的页面详细记录；详细文件中包含 diagnostic 与 samples。文件名带时间和随机编号，使用新建模式，绝不覆盖已有日志。助手离线时最多保留 10 份诊断，恢复服务后补交；达到上限会明确报错，保留缓冲，不无限积累。

桌面日志达到 1000 份或 64 MB 后暂停写入，并在队列显示写入错误；不会自动删除日志或其他文件。日志写入失败不冒充保存成功。

## 旧记录与重启

“导出旧失败日志”导出既有失败任务的基本记录，明确标注当时没有 DOM 诊断，不能补推具体原因。新详细诊断只在新版助手运行后采集。

重启清空的是当前手动读取状态。已收/捕获警告及旧失败任务属于持久化场次记录，仍保留；不代表刚重启又读到这些用户。需要新场次时先关闭监听，逐条处理或归档异常，等待助手缓冲确认为空，再点“开始新场次”。归档和切换场次不删除文件。

## 验证范围

已实际重建启动 EXE，检查日志独立落盘、敏感字段过滤、防覆盖、容量边界、离线缓冲及手动读取日志。独立 Edge 助手 → 身份验证/失败诊断 → 桌面等效目录写入 → 临时页关闭，以及随机模板/真实 FFmpeg/手动输出链路均自测。测试使用受控礼物页面，不等于用户真实直播现场验收；不宣称零漏单或现场故障已修复。

旧 Go 核心与 FFmpeg 二进制保留，未从原 Go 源码重建。新代码位于 components/runtime/v813_source。
